# CommentPulse — ML edition

В этой версии анализ тональности выполняется обученной моделью машинного обучения, а история хранится в SQLite.

## Технологии
- Python + Flask — сервер и API.
- RuSentiTweet — открытый русскоязычный датасет публикаций из социальных сетей (13 392 записи, ручная разметка).
- TF-IDF + Logistic Regression — классификация тональности.
- scikit-learn + joblib — обучение, оценка и сохранение модели.
- SQLite — постоянное хранение истории анализов и комментариев.

## Первый запуск (PyCharm)
1. Распакуйте архив и откройте папку `CommentPulse_Project` в PyCharm.
2. Выберите Python interpreter проекта.
3. В терминале выполните:
   `python -m pip install -r requirements.txt`
4. Подготовьте и очистите датасет:
   `python prepare_dataset.py`
   Скрипт скачает исходный CSV в `dataset/`, очистит данные и сформирует `reports/dataset_analysis.json`.
5. Обучите модель:
   `python train_model.py`
   Модель сохранится в `models/sentiment_model.joblib`, метрики — в `reports/model_metrics.json`.
6. Запустите `app.py`.
7. Откройте `http://127.0.0.1:5000`.

Можно выполнить шаги 4–5 одной командой: `python train_model.py` (он сам запустит подготовку данных, если очищенного CSV ещё нет).

## Структура
- `app.py` — Flask-приложение и REST API.
- `model.py` — загрузка модели и предсказание.
- `prepare_dataset.py` — загрузка, очистка и первичный анализ датасета.
- `train_model.py` — обучение и тестовая оценка.
- `database.py` — работа с SQLite.
- `dataset/` — исходные и очищенные CSV.
- `models/` — обученная модель.
- `reports/` — JSON-отчёты об анализе датасета и качестве модели.
- `instance/commentpulse.db` — SQLite база данных (создаётся автоматически).

## Методика обработки данных
Оставляются классы positive, neutral и negative. Классы speech act и skip исключаются, поскольку не соответствуют задаче определения полярности. Пустые записи и дубликаты удаляются; ссылки и упоминания пользователей заменяются служебными токенами; пробелы нормализуются. Разбиение train/test выполняется стратифицированно (80/20).

## Важное ограничение
RuSentiTweet содержит русскоязычные публикации Twitter/X общего домена, а не исключительно комментарии Instagram/TikTok/YouTube. Поэтому модель подходит как базовая модель анализа русскоязычных социальных текстов, но может хуже работать на казахском языке, сленге, сарказме и комментариях конкретных платформ. Поддержка казахского интерфейса не означает, что модель обучена на казахских текстах. Для полноценной казахской классификации потребуется отдельный размеченный казахский датасет и дополнительное обучение.

Реальные аккаунты соцсетей/API в проекте не подключены. Комментарии пользователь вставляет вручную или импортирует в будущей версии.
